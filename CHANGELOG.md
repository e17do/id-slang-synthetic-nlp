# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-20

### Added

- Initial structured synthetic Indonesian casual-language dataset.
- 10,000 synthetic language records.
- Sequential `ID-NLP-*` identifiers.
- Indonesian slang and internet expressions.
- Regional and demographic language variation.
- Social-media-oriented conversational expressions.
- Indonesian-English code-switching.
- Gaming, workplace, fintech, financial, relationship, and internet-culture language.

### Repository

- Added `README.md`.
- Added `LICENSE` for software/code.
- Added `DATASET_LICENSE.md` for dataset-specific terms.
- Added `.gitignore`.
- Added `CITATION.cff`.

### Quality Direction

The project establishes a roadmap for:

- schema validation;
- duplicate and near-duplicate detection;
- template/repetition detection;
- linguistic quality analysis;
- dataset statistics;
- reproducible validation;
- expanded metadata;
- NLP benchmarking.
