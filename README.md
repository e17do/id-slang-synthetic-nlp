## ENGLISH VERSION

### 📌 Asset Description
This repository contains a high-quality, structured synthetic dataset simulating various Indonesian local dialects, casual expressions (slang), Gen Z/Alpha digital lingo, and contextual emotional nuances. 

This asset is explicitly architected for training Large Language Models (LLMs), optimizing AI Chatbots, and refining localized sentiment analysis tools to interact naturally with Indonesian users.

### 🛡️ Compliance & Privacy
All data records in this repository are generated autonomously using generative algorithms without scraping, replicating, or exposing any real-world personal identifiable information (PII). Fully compliant with the Indonesian **Personal Data Protection Act (UU PDP)**.

### 📊 Data Schema
The dataset is structured in `JSON` format with the following parameters:
- `id`: Unique identifier for each data row.
- `konteks_percakapan`: Simulated Indonesian casual text/dialogue.
- `ragam_slang`: Specific slang words or phrases utilized in the sentence.
- `sentimen_emosi`: Emotional sentiment label (Positive, Negative, Neutral, Frustrated, etc.).
- `lokasi_dominan`: Estimated demographic or geographical origin of the linguistic style.

## VERSI BAHASA INDONESIA

### 📌 Deskripsi Aset
Dataset ini adalah kumpulan data sintetis terstruktur yang mensimulasikan ragam dialek lokal, bahasa kasual (slang), bahasa gaul Gen Z/Alpha, serta nuansa emosi kontekstual di Indonesia. 

Aset ini dirancang khusus untuk melatih Model Bahasa Besar (LLM), AI Chatbot, dan analisis sentimen lokal agar mampu memahami interaksi manusia Indonesia secara natural dan tidak kaku.

### 🛡️ Kepatuhan Hukum & Privasi (Compliance)
Seluruh baris data dalam repositori ini diproduksi secara otonom menggunakan algoritma generatif tanpa merekam, menyalin, atau mengekspos data pribadi manusia asli di dunia nyata. Kompatibel penuh dengan regulasi **UU Perlindungan Data Pribadi (UU PDP) Indonesia**.

### 📊 Struktur Data (Skema Data)
Berkas data disimpan dalam format `JSON` dengan parameter metrik sebagai berikut:
- `id`: Kode unik baris data.
- `konteks_percakapan`: Kalimat atau dialog kasual tiruan.
- `ragam_slang`: Istilah atau kata gaul yang digunakan dalam kalimat.
- `sentimen_emosi`: Label emosi di balik kalimat (Positif, Negatif, Netral, Frustrasi, dll).
- `lokasi_dominan`: Estimasi wilayah atau demografi asal gaya bahasa tersebut.
